Findings someone decided to live with, and why. They count again when the time is up or when an administrator withdraws the decision.

DENIS keeps watching them: it warns 14 days and 3 days before a decision ends, scans the open-port ones again once a day, and notes in the event log when a problem has gone away.

Network interfaces

The discovery interface does ARP sweeps, port scans and everything else DENIS does today. The mirror interface (optional) is capture-only — never probed, never used for discovery — for a switch mirror/SPAN port: it sees traffic between other devices that a normal port never would. Changing either needs a restart to take effect.
