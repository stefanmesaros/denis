Network interfaces

The discovery interface does ARP sweeps, port scans and everything else DENIS does today. Mirror interfaces (optional, any number) are capture-only — never probed, never used for discovery — for a switch mirror/SPAN port: each sees traffic between other devices that a normal port never would. One per VLAN, say, all on the same box, no separate agent needed. Changing either needs a restart to take effect.

HTTPS certificate

Download the CA certificate

For more than a couple of agents, this is usually simpler than copying the CA file to every machine: paste it as one value, e.g. DENIS_MASTER_CA_PEM, wherever you already push each agent's token.

System

Restarting picks up any configuration change that needs one, without losing the register. Both ask for your password again.

Single sign-on (OIDC)

Let people sign in through an identity provider (Entra ID, Okta, Google Workspace, Keycloak, anything speaking OpenID Connect) instead of a local password. The first sign-in for an email creates a viewer account for it automatically; raise its role afterwards like any other account. Local accounts, including the initial admin password, keep working alongside this.

Explain with AI

Optional, bring-your-own-key: adds an "Explain with AI" button to alerts and findings, one plain-language summary per click — never automatic, never sent anywhere unless someone clicks it. Each call is billed to your own account with the provider you choose; DENIS runs none of this itself. Only what the console already shows for that one alert or finding is sent — nothing else about your network.

Data retention

How long events, alerts and trend samples are kept before DENIS deletes them on its own. The asset register itself is never affected. Applies within the hour, no restart.

1 to 1095 days (3 years). 180 days (6 months) is a reasonable default; a busy network with flow accounting on can generate a large database over long periods, so keep this as short as your reporting needs allow.
