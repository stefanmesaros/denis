# Feedback and testing

Thanks for helping. DENIS is security software, so the bar is "works, is tested, and is explained".

## Bug reports and questions

Open an issue at <https://github.com/stefanmesaros/denis/issues>. Say which version you run (`denis --version`), what
you did, what you expected and what happened. Do not paste passwords, API keys, tokens or captures of production
traffic; describe the traffic instead.

## Testing on your equipment

Results from real networks and real equipment are the most useful thing you can send: which switch, firewall or
controller, which software version, what worked and what did not. [docs/community-testing.md](docs/community-testing.md)
says what is most wanted and how to send it.

## Translation corrections

The console speaks English, Deutsch, Français, Español and Slovenčina. If a text reads wrong, open an issue with the
language, the page and the text you would use instead.

## Security issues

Do not file them as public issues: see [SECURITY.md](SECURITY.md).
